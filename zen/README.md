# Zen — Project Ops, Automated

A concept demo for an AI-powered project-ops assistant: it turns meeting recordings into structured project updates — summaries, action items, decisions, and follow-ups — so a PM reviews instead of transcribes.

🏆 **This concept won first place at an internal company hackathon.**

**Note:** this is an original rebuild made for this portfolio. It's inspired by the general idea behind that hackathon project, but every line of code, all sample data, and the fictional company ("Northlight Robotics") were written from scratch specifically for public sharing — none of it reuses the original project's code, branding, or internal details.

## What's in the demo

- **Portfolio view** — sample projects with status, progress, and open action-item counts
- **Project drilldown** — a charter (why/what/success metrics), a RASIC responsibility matrix, action items you can check off, and a mock meeting feed with summaries and decisions
- **Export** — download action items as CSV, or copy a plain-text stakeholder brief
- **Pipeline view** — a step-by-step map of how the automation is meant to flow, end to end

All data is fictional and hardcoded for demonstration — there's no backend, no real integrations, and nothing here is connected to any real company or tool.

## Run it

Just open `index.html` in a browser — no build step, no dependencies.
